# Obtaining Token
To access our security client, you must first obtain an access token. This token can only be obtained by joining our waitlist of new users, or by identity verification with an ID, phone number or calling our international verification line. This is to assure not user can use our security client to exploit applications or commit legal crimes.

# Violations
If a user commits a violation to international cyber security laws or are violating our platforms policy, our admins would delete the token of the user and black list the user's identity from ever accessing our client. To protect user security, all user information are stored as an encrypted string, and the process of banning would not involve developer access to each user's identity.

# Reccomened OS
Our security client can not be downloaded as an application, and can only be put together with a terminal or our recommend tools. This is to assure users can not reverse our provided DNS functions to track the activities of other users.
